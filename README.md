# CVS Stock Entry Import

Extracts a Material Issuance Summary document (PDF/image) with AI and generates a
standard ERPNext Stock Entry (Material Issue).

### Installation

```bash
bench get-app cvs_stock_entry_import [git-url]
bench --site [site-name] install-app cvs_stock_entry_import
```
